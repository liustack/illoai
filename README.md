# IlloAI is now BeastCover

This project was renamed and now lives at **[liustack/beastcover](https://github.com/liustack/beastcover)**. It only makes covers: one command renders covers for WeChat, X, YouTube, Bilibili, Xiaohongshu, Instagram, Douyin, and TikTok.

```bash
npx -y skills add liustack/beastcover -g
```

This repository is archived and no longer updated.
